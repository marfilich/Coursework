# Курсовой проект
 
Разработка консольного приложения для создания, хранения и работы с файловой базой данных, содержащей характеристики AR/VR движков.

## Операции, разработанные в программе

1. Загрузка данных из бинароного файла
2. Просмотр всех записей
3. Поиск по целевой платформе и физике
4. Сортировка данных по квадратному корню из FPS
5. Добавление новой записи
6. Сохранение данных в бинарный файл
7. Генерация тестовых значений
8. Выход

## Поля структуры
- **Название** - ``name``\
  Тип данных: _char[]_
- **Целевая платформа** - ``target_platform``\
  Тип данных: _char[]_
- **Стабильный FPS** - ``stable_fps``\
  Тип данных: _float_
- **Поддержка физики** - ``physics_support``\
  Тип данных: _char_
- **Качество графики** - ``graphics_quality``\
  Тип данных: _enum_
- **Размер SDK** - ``size_sdk``\
  Тип данных: _float_
- **Стоимость лицензии** - ``license_cost``\
  Тип данных: _double_

## Пользовательские функции

### 1. `int count_data(const char* file_name)`
- **Назначение**: Подсчитывает количество записей в файле
- **Параметры**:  
  - ``file_name`` - имя файла для чтения
- **Возвращает**: количество записей в файле

### 2. `Engine* uploading_data(const char* file_name, int count, Engine* database)`
- **Назначение**: Загружает записи из файла в массив структур
- **Параметры**: 
  - ``file_name`` - имя файла для чтения
  - ``count`` - количество записей для загрузки
  - ``database`` - указатель на массив структур 
- **Возвращает**: указатель на заполненный массив структур 

### 3. `int output_engine(Engine* database, int count)`
- **Назначение**: Выводит все записи на экран
- **Параметры**: 
  - ``count`` - количество записей в массиве
  - ``database`` - указатель на массив структур
- **Возвращает**: **0** в случае успеха

### 4. `Engine* input_engine(Engine* database, int count)`
- **Назначение**: Добавляет новую запись в массив
- **Параметры**: 
  - ``database`` - указатель на массив структур
  - ``count`` - количество записей в массиве
- **Возвращает**: указатель на обновлённый массив структур

### 5. `int saving_data(Engine* database, const char* fname, int count)`
- **Назначение**: Сохраняет записи из массива структур в файл
- **Параметры**: 
  - ``database`` - указатель на массив структур
  - ``fname`` - имя файла для сохранения
  - ``count`` - количество записей в массиве
- **Возвращает**: **1** в случае успеха, **0** в случае ошибки

### 6. `int search_platform_physics_count(Engine* database, int count, char* search_platform, char search_physics)`
- **Назначение**: Подсчитывает количество записей, удовлетворяющих критериям поиска
- **Параметры**: 
  - ``database`` - указатель на массив структур
  - ``count`` - количество записей в массиве
  - ``search_platform`` - целевая платформа дял поиска
  - ``search_physics`` - нужная поддержка физики
- **Возвращает**: количество найденных записей

### 7. `Engine* search_platform_physics_array(Engine* database, int count, char* search_platform, char search_physics, int search_strings)`
- **Назначение**: Находит все записи, удовлетворяющие критериям поиска, и записывает их в новый массив
- **Параметры**: 
  - ``database`` - указатель на массив структур
  - ``count`` - количество записей в массиве
  - ``search_platform`` - целевая платформа дял поиска
  - ``search_physics`` - нужная поддержка физики
  - ``search_strings`` - количество найденных записей
- **Возвращает**: указатель на новый массив с найденными записями

### 8. `int compare(const void* a, const void* b)`
- **Назначение**: Функция сравнения для сортировки qsort()
- **Параметры**: 
  - ``a`` - указатель на первый сравниваемый элемент
  - ``b`` - указатель на второй сравниваемый элемент
- **Возвращает**: **-1**, если ``a`` < ``b``;  **1**, если ``a`` > ``b``;  **0**, если ``a`` = ``b``

### 9. `int sort_fps_in_the_square(Engine* database, int count, int (*compare) (const void*, const void*))`
- **Назначение**: Сортирует массив по квадратному корню из FPS
- **Параметры**: 
  - ``database`` - указатель на массив структур
  - ``count`` - количество записей в массиве
  - ``compare`` - указатель на функцию сравнения
- **Возвращает**: **1** при успешном выполнении, **0** при ошибке

### 10. `Engine* test(Engine* database, int last_count, int count)`
- **Назначение**: Генерирует тестовые значения
- **Параметры**: 
  - ``database`` - указатель на массив структур
  - ``last_count`` - индекс элемента, с которого начинается заполнения
  - ``count`` - количество записей в массиве
- **Возвращает**: указатель на заполненный массив структур
